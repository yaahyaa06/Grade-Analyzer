# Grade-Analyzer
A python program for analyzing grades and calculating student's performance 
## Features
- Enter multiple grades
- Calculates the average
- Shows the highest and lowest grades
- Gives a letter grade
- Shows whether you passed or failed
- Gives a short recommendations based on the average
- Checks for invalid inputs

## Built with
- Python

## How to run

```bash
python Grade_analyzer.py
```
